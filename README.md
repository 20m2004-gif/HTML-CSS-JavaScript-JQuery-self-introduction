# 自己紹介HP（HTML/CSS, JavaScript（JQuery））

## 概要
個人の自己紹介やスキル・作品をまとめた、シンプルな1ページ構成の自己紹介HPです。
HTML / CSS / JavaScript（JQuery）を用いて、以下のようなUIを実装しながらフロントエンドの基礎を学ぶことを目的としています。

- ヘッダーから各セクションへのスムーズスクロール
- アコーディオン形式でスキル・趣味の表示
- 作品スライダー（左右ぼたん + スマホでのスワイプ対応）
- ダークモード切り替え
- ページトップボタン

自己紹介だけでなく、ものづくりを視覚的に伝えられる構成にしています。

## 構成ファイル
- 'HP.html'
  - ページ全体の構造（自己紹介 / スキル / 趣味 / 連絡先セクション）
  - ものづくりカード内にスライダーを配置
-'HP1.css'
  - 全体レイアウト、カラーリング（青系）、タイポグラフィ
  - セクション、アコーディオン、作品スライダー、ダークモードのスタイル定義
- 'HP2.js'
  - JQueryを用いたインタラクション制御
  - ナビゲーションのスムーズスクロール
  - アコーディオン開閉
  - 作品スライダー（左右ボタン + スワイプ）制御
  - ページトップボタン表示/非表示
  - ダークモード切り替え

## 主な機能
### 1. 自己紹介セクション
- 左側アイコン、右側にテキストを配置したレイアウト
- 『詳しく見る』ボタンで詳細プロフィールをアコーディオン表示

### 2. スキルセクション
- プログラミング / データ分析 / その他 といったスキルカテゴリを見出しとして表示
- 見出しクリックで説明文を開閉できるアコーディオン UI
- 一度に表示しすぎず、読みやすさと情報量のバランスを意識

### 3. 趣味セクション
- ものづくり / パソコンいじり / 学び といったカテゴリを見出しとして表示
- ものづくり内に作品スライダーを配置
  - 左右のボタンで作品を切り替え
  - スマホ・タブレットではスワイプ操作で作品を切り替え
  - 各スライドで作品画像 + キャプションを表示
-  作品はJavaScriptの配列 ('slides') に定義しており、
   画像ファイルとキャプションを追加することでスムーズに作品を増やせる構成にしている

### 4. 連絡先セクション
- 将来的にSNSリンクを掲載するためのプレースホルダーとして用意
- 目立ちすぎない範囲で強調したボックスデザイン

### 5. 共通UI
- ページ右下にトップページボタンを設置（一定スクロールで表示される）
- ヘッダーから各セクションへのスムーズスクロール
- ダークモード切り替えボタン

## 使用技術
- HTML5
- CSS3
- JavaScript（JQuery）

## 工夫したポイント
- **『見やすさ』と『自分らしさ』の両立**
  自身の好きな青系を基調とした配色で統一しつつ、作品部分にはイラスト・ハンドメイドの世界観が伝わるように構成しました。
- **作品の追加のしやすさ**
  作品スライダーは、JavaScript内の'slides'配列にオブジェクトを追加するだけで作品を増やしやすいように実装しました。
- **シンプルなコード構成**
  1ページ構成 + 3ファイル（HTML / CSS / JavaScript）に分けたシンプルな構成にしました。
